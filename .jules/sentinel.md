## 2023-11-06 - Vulnerability in `gitExecWithDir`
**Vulnerability:** Argument injection/command injection via `strings.Split(strings.Join(args, " "), " ")`
**Learning:** `gitExecWithDir` accepts multiple strings as arguments, joins them into a single string with spaces, and then splits them by spaces again. If an argument intentionally contains spaces (e.g. file paths, commit messages, URLs), they will be split into separate arguments to `git`. More dangerously, if any caller passes a single string containing spaces expecting it to be executed as a single command, an attacker might be able to inject additional arguments to `git`. This is a classic injection pattern when arguments are joined and split by whitespace before being passed to `exec.Command`.
**Prevention:** Avoid joining and splitting arguments before passing them to `exec.Command`. `exec.Command` inherently handles passing arguments correctly to the executed binary. Simply pass the arguments as a slice/variadic arguments without modification.
