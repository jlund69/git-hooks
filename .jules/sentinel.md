## 2024-05-18 - Fix Command Injection Vulnerability in gitExec
**Vulnerability:** The application was vulnerable to command injection because `gitExec` and `gitExecWithDir` split arguments from a single space-separated string before passing them to `exec.Command`. This allowed malicious user input to inject arbitrary commands.
**Learning:** `exec.Command` in Go should be given individual arguments as separate strings rather than a single string that is later split, to prevent arguments with spaces or shell metacharacters from being misinterpreted. The `strings.Split(strings.Join(args, " "), " ")` pattern effectively undoes the safety provided by `exec.Command`'s variadic argument handling.
**Prevention:** Pass arguments as separate string elements (e.g., using a string slice or variadic arguments) directly to `exec.Command` or wrapping functions. Do not concatenate and re-split command arguments. Ensure configuration values used as commands are defined as slices rather than single strings.
