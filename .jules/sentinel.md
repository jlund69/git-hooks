## 2024-05-18 - [Command Injection via String Splitting]
**Vulnerability:** The application was vulnerable to command injection because `util.go`'s `gitExecWithDir` function joined arguments with a space and immediately re-split them by space before passing them to `exec.Command`. This meant an argument originally intended as a single value (e.g., a URL containing spaces) would be treated as multiple independent arguments or flags by the `git` command, allowing a malicious user to inject arbitrary git flags like `--upload-pack`.
**Learning:** Even when inputs seem controlled, manipulating arrays of arguments into strings and back again bypasses the inherent protections of `exec.Command`. Global configuration state (like `GIT` map commands) storing pre-joined command strings encourages this vulnerable pattern downstream.
**Prevention:** Always use typed string arrays or slices (`[]string`) for command definitions and variadic arguments. Never serialize and deserialize argument arrays via `strings.Join` and `strings.Split(" ")`. When configuring commands globally, use `map[string][]string` rather than `map[string]string`.
