## 2024-05-19 - Fix command injection vulnerability in gitExecWithDir
**Vulnerability:** The `gitExecWithDir` wrapper concatenated and re-split command arguments around spaces (`args = strings.Split(strings.Join(args, " "), " ")`), effectively causing arguments containing spaces to be improperly split and breaking execution predictability. Callers relied on passing raw concatenated strings (like `gitExec("config --get hooks.global")`) exposing the CLI to potential command or argument injection via unsanitized strings or path components with spaces.
**Learning:** This repo's execution wrappers were historically treating slices incorrectly by conflating list structures with shell-like string execution contexts. This pattern existed because the `GIT` configuration map was stored as raw strings and simply prepended/appended to.
**Prevention:** Always separate command arguments out individually when interfacing with `os/exec` directly, explicitly utilizing array types (like `[]string`) to store and construct dynamic payloads. Do not perform `strings.Split` and `strings.Join` tricks on CLI arguments inside generic wrappers.
