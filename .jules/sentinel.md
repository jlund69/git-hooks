## 2024-05-15 - Command Argument Injection via String Splitting
**Vulnerability:** Argument splitting in wrapper functions around `os/exec.Command` can lead to command injection or unintended flag injection. The function `gitExecWithDir` was taking a variadic string slice and effectively flattening and resplitting it: `args = strings.Split(strings.Join(args, " "), " ")`. If an argument dynamically passed contained a space, it would be treated as multiple arguments.
**Learning:** We must not implement our own command line argument splitting logic (like `strings.Split(" ")`) because it ruins the explicit boundaries defined by the developer when they construct command arguments. `exec.Command` expects a clean list of arguments.
**Prevention:** Always pass arguments to `exec.Command` as individual slice elements exactly as provided by the caller. Treat string inputs that need to be part of the command as atomic entities rather than space-separated tokens. Avoid concatenating strings to form command lists.
