## 2024-05-15 - Command Injection via String Joining in exec.Command
**Vulnerability:** The `gitExec` function was vulnerable to command injection because it accepted varargs strings, joined them with spaces, and then split them by space, passing them to `exec.Command`. If a user input (e.g. from `clone %s %s` using remote URLs) contains spaces and shell characters, it could be executed as a separate argument or lead to unintended commands.
**Learning:** This codebase previously assumed `exec.Command` would be secure if using varargs, but explicitly combining and splitting varargs (`args = strings.Split(strings.Join(args, " "), " ")`) undermines the array-based argument safety of `exec.Command` which prevents command injection by avoiding the shell.
**Prevention:** Pass arguments to `exec.Command` and wrapper functions as separate strings using slices (`[]string`) or distinct varargs. Never join and split arguments back into arrays before passing them to `os/exec` functions.
