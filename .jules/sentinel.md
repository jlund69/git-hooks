## 2024-05-18 - Fix Command Injection via string splitting in exec
**Vulnerability:** The `gitExecWithDir` function previously took variadic string arguments, joined them into a single string separated by spaces, and then split them again by spaces before passing them to `exec.Command`. This allowed for command injection or argument splitting if any individual argument contained a space. Also, the `GIT` configuration map previously contained strings instead of string slices, making them susceptible to being passed in a single string that required space splitting.
**Learning:** Command arguments should be strictly maintained as slices of separate arguments right up to the invocation of `exec.Command`. Doing a join-and-split operation breaks any argument boundaries that might be properly configured by the caller and makes passing paths or inputs with spaces insecure.
**Prevention:** Use string slices (`[]string`) in configuration when commands have arguments. Use variadic inputs strictly for passing multiple arguments explicitly (`cmd := exec.Command("git", args...)`). Avoid `strings.Split` or `strings.Join` with space delimiters to prepare command arguments.
