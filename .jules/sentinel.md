## 2023-10-26 - Prevent Command Injection in Git Executions
**Vulnerability:** The application was passing string slices for git command arguments, joining them with spaces, and then blindly splitting them back by spaces before execution using `exec.Command`. This makes command components vulnerable to unexpected interpretation if argument inputs contain spaces. Some internal commands were dynamically constructed strings (e.g. `fmt.Sprintf("clone %s %s", url, path)`) parsed using the same vulnerable logic.
**Learning:** Command line argument handling should always use native array/slice types to securely delimit positional arguments rather than depending on string space splitting and joining, which introduces unexpected tokenization.
**Prevention:** We have modified `GIT` configuration dictionary mappings to explicitly track command elements natively as `[]string`, and eliminated `strings.Split(strings.Join(args, " "), " ")` directly inside the `gitExecWithDir` base function.
