## 2024-05-15 - Command and Argument Injection via `strings.Split`
**Vulnerability:** Argument Injection and Command Injection. The codebase previously combined variadic arguments into a single string joined by spaces, and then blindly split it by spaces before passing it to `exec.Command`. (e.g., `args = strings.Split(strings.Join(args, " "), " ")`).
**Learning:** This approach completely defeats the purpose of providing multiple arguments to `exec.Command` natively, and introduces a vulnerability where arguments that naturally contain spaces (like paths, branch names, or messages) are improperly split, enabling an attacker to inject arbitrary command line flags or change the command's meaning.
**Prevention:** Always pass arguments to `exec.Command` directly as individual items in a string slice. Do not combine and resplit string arguments. Any configuration (like the `GIT` map in `config.go`) representing multiple command parts should be inherently stored as a `[]string` rather than a space-separated `string`.
