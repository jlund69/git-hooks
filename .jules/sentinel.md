## 2024-05-18 - Prevent Command Injection in exec.Command and gitExec
**Vulnerability:** The `gitExec` function joined all arbitrary arguments using `strings.Join(args, " ")` and then split them by space `strings.Split(..., " ")`. This causes any argument passed to `gitExec` that contained spaces to be split into multiple arguments when passed to `exec.Command`. It can allow malicious configurations or paths to inject arbitrary arguments or flags into Git commands, which can sometimes lead to arbitrary command execution (for instance, by abusing `git config` or aliased commands). It is fundamentally insecure to build command arrays by joining and splitting strings, because quoting rules are not preserved.
**Learning:** Argument slices in Go's `os/exec` must remain as distinct strings. Flattening arguments with `strings.Join` and `strings.Split` breaks up paths with spaces and enables injection of arguments by manipulating paths or configuration variables.
**Prevention:** Never use `strings.Join` followed by `strings.Split` to parse arguments for `os/exec`. Keep the arguments in the `[]string` slice exactly as they are provided, or use standard append logic if adding more arguments. When calling `exec.Command` in this codebase, always pass arguments as separate strings (e.g., using a slice or variadic arguments) rather than joining them into a single space-separated string to prevent argument and command injection vulnerabilities.
