## 2024-05-24 - [Argument Injection in Exec]
**Vulnerability:** Found an argument injection vulnerability where `util.go:gitExecWithDir` was taking untrusted inputs, joining them into a single string by spaces, and splitting by spaces, before passing them to `exec.Command`. This could be exploited to bypass command boundary logic, injecting arbitrary Git flags or other dangerous commands (e.g. `--config core.hooksPath=...`).
**Learning:** We must not merge and then split by spaces when passing arguments to `exec.Command` in Go. `exec.Command` inherently handles passing arguments correctly, but this approach defeated that design pattern and led to argument injection. It existed because the developer might have mistakenly believed joining then splitting would format arguments properly.
**Prevention:** Avoid re-parsing of arrays of arguments in system execution functions like `exec.Command`. If arguments might contain spaces, passing them as discrete array elements is standard and safe against injection.
