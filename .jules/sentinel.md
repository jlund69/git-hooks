## 2024-05-18 - Fix command injection in gitExec
**Vulnerability:** The `gitExec` and `gitExecWithDir` functions in `util.go` were vulnerable to argument and command injection because they joined all arguments into a single string using `strings.Join(args, " ")` and then split them using `strings.Split(..., " ")`. This allowed commands with spaces or arbitrary bash operators if the arguments were partially controlled by variables or environment parameters.
**Learning:** Command execution functions must maintain exact separation of arguments when passing them to `exec.Command` to prevent injection attacks and ensure robust handling of arguments with spaces (like directories). The `GIT` configuration map was also incorrectly using space-separated strings to represent multi-argument commands.
**Prevention:** Pass arguments to `exec.Command` exactly as they are without using `strings.Join`. Ensure configuration maps intended to hold commands use `[]string` instead of `string`. Use `append([]string(nil), slice...)` to safely pass slice arguments to variadic functions dynamically without mutating globals.
