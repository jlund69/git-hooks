## 2023-11-20 - [Command Injection via String Joining/Splitting in exec.Command]
**Vulnerability:** The function `gitExecWithDir` joined and re-split variadic arguments using spaces. If an argument contained a space (e.g., a file path or user input), it would be improperly broken into multiple arguments by `strings.Split(strings.Join(args, " "), " ")`, leading to potential command/argument injection vulnerabilities when executing `exec.Command`.
**Learning:** This existed because of an attempt to handle improperly passed strings by concatenating and splitting them again, breaking the safety natively provided by passing slices of strings to `exec.Command`.
**Prevention:** Avoid joining and splitting strings when dealing with shell commands. Always execute commands with safely separated string slices for arguments instead of constructing a single command string. Ensure global slice configurations like `GIT["SetTemplateDir"]` are sliced into separate strings appropriately (e.g. from `map[string]string` to `map[string][]string`) and always append them using a new nil slice (e.g. `append([]string(nil), slice...)`) to prevent global map mutation.
