## 2024-11-09 - Command Injection in Git Exec
**Vulnerability:** Command arguments to `gitExec` and `gitExecWithDir` are passed as separate slice items, but `gitExecWithDir` concatenates all arguments using `strings.Join(args, " ")` and re-splits them `strings.Split(..., " ")`. This creates a command injection vulnerability where a space in an argument causes it to be split into multiple arguments to `git`, and an attacker controlling an argument could pass malicious arguments (or use git options like `--exec-path` to achieve command execution).
Furthermore, `GIT` config map uses space-separated strings, which are then passed to `gitExec(GIT["Command"])`. Wait, they are parsed incorrectly!
**Learning:** Argument slices should never be joined and re-split, as this causes loss of argument boundaries, making space-containing arguments split, which breaks correctness and security.
**Prevention:** Pass the arguments slice directly to `exec.Command` or use an appropriate `exec.Command("git", args...)`. Ensure callers pass discrete arguments instead of space-separated strings, e.g., use `map[string][]string` for predefined commands or pass variable length arguments correctly.
