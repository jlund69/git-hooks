## 2024-10-24 - CLI Status Indicators
**Learning:** Adding visual cues like colors (green for success/installed, yellow for warning/not installed) and unicode icons (✔, ✗) significantly improves the scannability of CLI status outputs.
**Action:** Use `github.com/wsxiaoys/terminal/color` syntax (e.g., `@g✔`) to enhance important CLI status messages with color and icons.
