## 2024-05-24 - CLI Output Colorization Pattern
**Learning:** In this Go CLI (`git-hooks`), output formatting uses `github.com/wsxiaoys/terminal/color` within a custom logger (`logger.go`). This library parses inline tags like `@c` (cyan), `@g` (green), `@y` (yellow), and `@m` (magenta). When adding UI colorization, these tags must be prepended directly to the strings passed to the logger (e.g., `logger.Infoln("@c" + msg)`) rather than modifying the static string constants in configuration maps (`MESSAGES` in `config.go`) to maintain separation of concerns. Additionally, because the test suite intercepts and stores these exact logged arguments, test assertions must be updated to match the formatted strings including the tags (e.g., `"@y" + MESSAGES["NotGitRepo"]`).
**Action:** When adding color to CLI output in this app, prepend color tags directly in the presentation/logging layer and immediately update the corresponding assertions in the test suite to match the newly formatted strings.
