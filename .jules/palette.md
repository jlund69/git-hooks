## 2024-06-01 - CLI Color Cues
**Learning:** Adding semantic color tags (like `@g` for success/installed and `@y` for warnings/missing) to CLI application logs significantly improves the at-a-glance readability and user experience in the terminal.
**Action:** When implementing CLI commands that output state or status, always use appropriate terminal color codes to highlight critical information instead of relying solely on plain text.
