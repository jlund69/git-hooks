## 2024-05-24 - CLI Output Colorization
**Learning:** Adding subtle color cues to a CLI tool's output using terminal color codes (e.g. `@c` for cyan, `@r` for red) greatly improves readability by visually grouping related information and highlighting key states.
**Action:** When working on CLI apps, look for opportunities to apply semantic colors to standard outputs (like success, warning, error, or distinct headers) instead of relying solely on plain text formatting.
