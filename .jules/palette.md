## 2023-10-31 - Improved CLI list output hierarchy with terminal colors
**Learning:** In CLI applications, flattening complex hierarchical data (like scopes -> triggers -> repos -> hooks) without visual differentiation makes it very difficult for users to scan and parse the information quickly. Relying solely on indentation isn't always enough for accessibility and readability.
**Action:** Use native terminal color libraries (e.g., `github.com/wsxiaoys/terminal/color`) to visually distinguish different levels of information. For example, using distinct colors for category headers, event triggers, and list items dramatically improves the scannability of the output without relying on external libraries or altering the underlying data structure. Remember to prepend the string color tags (like `@c`, `@m`, `@g`) directly in the print functions rather than modifying configuration constants to keep separation of concerns.
