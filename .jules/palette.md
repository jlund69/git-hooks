## 2024-05-24 - Visualizing installation status in CLI tools
**Learning:** Adding intuitive color formatting (e.g. red for error/not found, yellow for neutral/warning, green for success) directly to CLI output strings significantly improves the user's ability to quickly parse the status of their environment at a glance. In this repo, the `wsxiaoys/terminal/color` package parses tags inline like `@r`, `@g`, and `@y` effortlessly.
**Action:** When working on CLI outputs in Go using terminal color packages, leverage inline color tags for important status messages rather than keeping everything monochrome, and remember that when testing these functions, testing frameworks may record the raw text output including the inline tags if the test logger catches them before formatting.
